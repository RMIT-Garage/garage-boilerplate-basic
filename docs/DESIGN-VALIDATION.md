# UX Design Validation

**Role:** Business Analyst - Haidar Malik  
**Sprint:** Mock Sprint - Bootstrap Restyling  

## 1. Purpose

This document records the validation of the UX wireframes against the Team Page and Login Styling requirements.

## 2. Team Page Validation

The Team Page wireframe was reviewed against the requirements.

The following required elements are represented in the design:

- Member photo/avatar
- Member name
- Member role
- Short member blurb
- Consistent layout for each team member
- Consistent sizing of member images
- Text displayed without overlapping other content

The design meets the required Team Page display requirements.

## 3. Login Page Validation

The Login Page wireframe was reviewed against the defined styling scope.

The design remains within the **styling-only** scope and does not propose changes to:

- Authentication logic
- Existing login functionality
- Firebase/authentication configuration
- Session behaviour
- User permissions
- Existing login validation logic

The proposed changes are limited to visual elements such as layout, typography, spacing, colours and component styling.

## 4. Edge Case Validation

The design was reviewed with the documented edge cases in mind, including:

- Missing member photos
- Long member names
- Long member blurbs
- Missing member blurbs
- Different screen sizes

No outstanding requirement gaps were identified during the design review.

## 5. BA Approval

The UX wireframes have been validated against the documented requirements.

The design is **approved from the Business Analyst requirements perspective** and is ready to proceed to implementation.
