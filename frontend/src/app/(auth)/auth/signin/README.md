#Sign in Page

##Bootstrap Restyling

The existing sign in page was restyled in order to match the required design decisions within the approved UX Design.

###Visual Changes

- Updated login card layout and spacing
- Updated Colour theme
- Restyled inputs for email and password
- Restyled sign in button
- Inputted icons

##Scope
The restyling stayed within the scope, leaving anything that could affect authentication logic, validation, Firebase configuration, session handling, or user permissions were left untouched.

The same functionality for all remains.
